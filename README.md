# algoritmus-zarovnavani-optickych-elementu
algoritmus, který je schopen nalézt a správně identifikovat referenční a parazitní body nasnímané kamerou optického interferometru. Dále je cílem algoritmu rozpoznat odraz od transparentního vzorku, jako je rovinné sklo nebo čočka, a určit jeho polohu a poloměr.
